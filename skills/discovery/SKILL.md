# Discovery

把 Owner 的模糊想法澄清为可验证的发现（吸收 BMAD Discovery / PRD 方法论）。

## 输入

- `idea`：Owner 原始想法
- `feasibility`：初步可行性判断

## 输出

- `discovery`：关键问题澄清、假设、开放问题清单、真实需求边界

## 权限

- OWNER + PLANNER

## 禁止行为

- 不编造事实或数据
- 不跳过未澄清的关键点
- 不替 Owner 做出产品决策

## 完成标准

- 关键问题已被澄清或显式标记为「待 Owner 回答」
- 假设与开放问题清单完整，可供下一步 requirement 使用
