# Research

调研技术可行性、现有方案与平台能力（吸收 OpenSpec Context Rules / BMAD 调研思想）。

## 输入

- `concept`：产品概念

## 输出

- `research`：技术选型依据、风险清单、可复用方案、待验证项

## 权限

- PLANNER

## 禁止行为

- 不引入未经验证的依赖
- 不臆测 API / 框架行为，须有来源
- 不先给结论再找证据

## 完成标准

- 关键技术决策均有依据来源
- 风险与替代方案已列出
